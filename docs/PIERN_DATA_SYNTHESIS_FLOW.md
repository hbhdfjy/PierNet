# PierNet 数据合成流程说明

## 1. 数据合成的目标

PierNet 的数据合成并不是让大语言模型凭空生成物理计算结果，而是把用户已有的科学计算数据整理成能够训练 Router、Text2Comp 并验证专家模型的标准数据集。最终推理链路为“用户问题 → Router → Text2Comp → Expert → 物理结果”，因此数据合成需要同时准备路由判断、专家输入参数生成和专家结果评测所需的数据。

## 2. 输入数据

用户可以上传自己的 HDF5 数据，也可以运行已有仿真程序，或调用已经注册且支持数据生成的专家模型。无论来源是哪一种，系统都会先检查样本数量、参数维度、输出形状和数值有效性，再将数据整理为统一结构。典型 HDF5 数据包含输入参数 `params [N, P]`、物理输出 `timeseries [N, C, T]` 和参数名称 `param_names [P]`。

## 3. 处理流程

1. **接入与校验**：读取用户数据、仿真结果或专家模型输出，检查文件格式、数组维度、空值和非法数值。
2. **确认数据定义**：确认场景名称、任务说明、专家输入参数的名称、顺序与单位，以及物理输出通道和采样方式。AI 可以补全便于人理解的字段说明，但不会改变数据维度和参数顺序。
3. **生成语言模板**：根据已确认的任务与参数生成不同表达方式的用户问题，为后续语言模型训练提供输入文本。
4. **生成 Text2Comp 数据**：建立“用户问题 → 专家模型输入参数”的样本。Text2Comp 的标签是专家模型需要接收的输入向量，不是专家模型计算后的物理输出。
5. **生成 Router 数据**：围绕当前目标场景构造正样本和负样本，形成当前使用的二分类 Router 数据，使 Router 学会判断问题是否应交给该场景处理。以后可在保持数据契约清晰的前提下扩展到多分类路由。
6. **生成专家评测数据**：保存专家输入参数及对应的真实物理输出，用于验证专家模型和整条 PierNet 推理链路是否正确。
7. **校验与登记**：检查三类数据的数量、维度、字段和关联关系，为数据集分配稳定 ID，然后交给简洁训练或复杂训练使用。

## 4. 生成产物

| 数据集 | 核心内容 | 主要用途 |
| --- | --- | --- |
| Text2Comp 数据 | 用户问题、专家输入参数 | 训练自然语言到计算参数的转换 |
| Router 数据 | 用户问题、目标/非目标标签 | 训练当前二分类路由判断 |
| 专家评测数据 | 专家输入参数、真实物理输出 | 验证专家模型及端到端推理结果 |

## 5. 主要难点

第一，**数据契约必须严格一致**。专家输入参数的名称、顺序、维度和单位只要有一项错位，即使模型能够运行，也可能得到物理意义完全错误的结果。第二，**Text2Comp 标签与物理输出容易混淆**。Text2Comp 学习的是如何生成专家输入参数，物理输出只用于专家评测，两者不能混用。第三，**语言样本既要多样又不能改变原意**。模板表达过于单一会限制模型泛化能力，但改写偏离任务含义又会引入错误监督。第四，**Router 负样本质量决定路由边界**。只增加数量而没有足够相似、容易混淆的负样本，Router 可能在简单测试中表现良好，却无法处理真实问题。第五，**科学计算输出形态差异很大**。不同专家模型可能输出标量、向量或长时序，系统必须保存真实形状和采样信息，不能依靠名称猜测。

## 6. 建议的使用与验证方式

首次接入新数据时，应先用少量样本完成一次全流程，随机检查 Text2Comp 标签是否等于正确的专家输入，检查 Router 正负样本是否符合场景边界，并调用专家模型核对评测数据的输出形状。小批量验证通过后再扩大数据量，同时记录源数据哈希、字段定义、随机种子和生成配置，保证后续训练结果可以追溯和复现。
